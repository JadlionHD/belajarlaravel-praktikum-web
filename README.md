# Praktikum Pemrograman Web 2

## Deskripsi
Aplikasi sederhana menggunakan Laravel sebagai backend dan Vue sebagai frontend.

## Teknologi
- PHP dan Laravel
- Composer
- Vue dan Vite
- Node.js dan NPM
- PostgresSQL
- Git

## Frontend dan Backend
Frontend dan Backend menjadi sudah menjadi satu bawaan dari Laravel


## Arsitektur
Browser -> Vue -> Laravel API -> Database
